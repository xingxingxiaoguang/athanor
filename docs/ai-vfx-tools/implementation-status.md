# 当前状态

资产组织与命令见 [ASSETS](../ASSETS.md)。SDK/创作工具维持 1.3.0 的机制能力；本轮整理源码、统一演示入口、更新入库依赖路径适配并清理生成历史，没有新增 VFX 算法。

原有 293 个正式资产保持 ID；8 个原创源码以 `studies` 状态保留。`asset.status` 与用户美术验收不同，不能把进入可复用源码库当成新的美术批准。最新烟体没有自动覆盖火球作品内的烟实现。

工作流支持普通 JS、公开契约发现、结构化诊断、冻结运行、原尺寸探查/对比、验证、选版、同 run 导出和入库恢复。机制见 [公开 API](authoring-api.md)。技术测试与独立创作评价分别报告；不据此宣称美术优越或节省时间。
