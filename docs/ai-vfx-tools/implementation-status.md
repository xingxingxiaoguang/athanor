# 像素特效工具台实施状态

日期：2026-11-06。分支：`codex/ai-vfx-lab-mvp`。本文说明现行可用能力、证据边界和实施顺序；产品目标见[产品全景](README.md)，逐项研发与验收要求见[交接工作包](HANDOFF.md#9-后续研发路线具体工作包与验收)。

当前有 **9个公开工具、19族公开API、15个SDK命名空间、9份机制配方**。A契约与证据底座已有交付；B创作核心已有路径、图像和粒子子集，完整身体/动作场景尚未验收；C已有部分观察能力，正式复用与受控探索未交付；D生产扩展尚未验收。动画交付和观察属于优先补齐的生产链路，不代表D阶段整体完成。

## 现行工作流

| 能力 | 可用入口 | 实际边界 |
| --- | --- | --- |
| 发现与契约 | `fx_search / fx_inspect` | 可查作品、算子及机制配方；单位、默认值、示例和限制见[公开API](authoring-api.md)；正式部件提取/装配未实现 |
| 建稿与运行 | `fx_scaffold / fx_render` | 普通`meta + draw/create`；空白或示例起点；固定源码、依赖、后端、参数和采样身份 |
| 原图观察与比较 | `fx_probe / fx_compare` | 保存preview/color/light/combined；自选事件/绝对时刻；报告实际帧、误差与条件差异；原尺寸分段网格和局部循环尚未统一交付 |
| 状态观察 | `fx_probe`与可选`observe` | 已声明的粒子、真实源、接触事件和历史；不自动发现自画主体，不从像素反推身份 |
| 历史与重放 | `fx_history / fx_render {target:{run}}` | 分页找版本；显式冻结重放生成子run；不把最新条目自动当作作者选择 |
| 技术验证 | `fx_validate {run}` | 重放冻结源，抽样检查确定性、边界、结束与更新率；不是美感、全部保存帧或引擎认证 |
| 图集交付 | `fx_export {run,validationRef}` | 同run验证关联，Aseprite风格JSON及color/light/combined PNG；没有直接MP4/GIF导出 |

CLI、MCP、HTTP共用[现行Schema](../../experiments/vfx-lab/definitions.mjs)。[目标工具契约](tool-contracts.md)包含未实现的设计，不能直接用作当前请求。实验页面支持保存run播放和对比，角色仅作站立尺度参照；完整act尚未接入lab。

## 已交付的创作能力

| 能力群 | 可用子集 | 重要限制 |
| --- | --- | --- |
| path与连续条带 | polyline、自适应cubic、弧长、切法线、重采样、连续可变宽strip | 分段近似；程序条带与粒子真实历史不同 |
| random与curve | 具名稳定通道，scalar/color，linear/hold/smooth，解析单侧导数及仿射/和/乘积组合 | smooth是逐段smoothstep；不等于任意Bezier/Hermite |
| domain与schedule | 点、扇环、圆、矩形、Path、Mask采样；burst/rate/resident/cycle及重叠周期副本 | 出生域不隐含速度；distance排期未实现 |
| motion与particle | 解析分轴阻力、120Hz force/radial/attract/kill；独立初始属性、生命周期、材质和自写trajectory | 没有任意几何碰撞或完整约束；自写velocity是作者声明，未自动证明等于位置导数 |
| 源轨迹 | source/pathSource/sampledSource；平移、旋转、父子源与出生点速度继承；真实源观察 | 显式差分没有通用误差界；身体挂点/动作时钟尚未适配 |
| texture与material | RGBA/ASCII/拆帧/序列/轴心/最近采样；火、烟、余烬、火花、mote、streak、水滴、涟漪成熟画法 | 外部图片/URL资产包未冻结；程序画法的变换需遵循各自契约 |
| mask/field/image/light | polygon/布尔/轮廓/差分，标量/噪声/rank/arrival，消融/首次出生与同源光 | 区间变化不等于精确瞬时事件；没有完整向量场、advect或身体表面协议 |
| contact | 点主体对静态水平面的解析到达、反弹/停留/停止/死亡，稳定事件与幂等二次出生 | effect空间、恒加速度/分轴阻力；不支持与任意force/trajectory混用 |
| trail | 固定出生网格重建，秒/采样像素长度，corner/break、驻留、死亡策略、真实观察 | effect空间、每轨道≤12秒；无任意空间误差、纹理UV带或透明多层织物保证 |

实现来自原244个效果、分类辅助模块和core，以及Spine Particle底层机制对照。保留成熟代码的来源署名；直接复用、通用化和候选边界见[实现地图](implementation-map.md)。

## 生产检验对实施方向的约束

依据独立作者的[龟派气功波日志](../../experiments/vfx-lab/productions/2026-11-06-anime-vfx/kamehameha/production-log.md)和[地爆天星日志](../../experiments/vfx-lab/productions/2026-11-06-anime-vfx/chibaku-tensei/production-log.md)，研发同时承担创作机制与完整生产流程：

| 已观察到的负担 | 应由工具承担的部分 | 保留给作者的选择 |
| --- | --- | --- |
| 各自编写图集解包、编码、密集帧拼接与记录脚本 | 选定冻结run的媒体交付、原尺寸分段观察、公共调用/分析记录 | 观察哪个事件、怎样解释画面、选择哪版 |
| 气功波为有意出画补写底层裁切包装 | 显式视口/资产边界、颜色与光一致裁切、越界时间和区域定位 | 镜头构图、是否让束头出画 |
| 气功波手写手部位置及发射同步 | 复用act/rig的共享时钟、挂点与空间变换 | 人物设计、动作夸张和发射节奏 |
| 地爆天星自画岩块不能被probe自动观察 | 同一主体状态连接变换、绘制与显式观察；分层/遮挡适配 | 独特形状、球壳材质、构图与层次 |
| 聚合质量、目标面和到达联动手写 | 到达记录、累计量和主体变化绑定的候选机制 | 质量模型、增长轮廓与夸张规则 |
| 束头、退场和聚合关系经多轮看图才收敛 | 可拆技法与围绕艺术假设的受控局改比较 | 艺术假设、替换方向与最终评价 |

这些要求不等于能力已经交付。开放代码入口使这两部作品可完成，不能据此推断所有创意都不受限。作者实际使用了成熟材质、随机、寿命、接触和历史；没有匹配基线，不能宣称净节时或能力飞跃。

## 运行与交付边界

- 纯作品按请求时间求值；模拟使用实验固定120Hz后端。旧run保留保存后端，原库运行时保持兼容。
- 冻结重放只支持可捕获的相对本地JavaScript闭包，并要求原Node版本、platform、arch。外部文件、动态导入、包与环境依赖未完整冻结时返回`REPLAY_UNAVAILABLE`，不回退到当前稿。
- 最大尺寸每轴480艺术像素、时长12秒、fps为12/24/30/60、渲染预算2400万帧像素；观察总预算16MB。invoke单次90秒/4MB返回限制。超限拒绝，不静默降质。
- light用黑色加法中性底、曝光1检查；color保存straight RGBA。combined普通alpha仅近似附加光。
- `validate {run}`的`savedFramesVerified:false`表示冻结源码抽样检查。生产案例的512帧逐像素核对不是所有run的自动认证。
- raw和隔离快照在ignored `records/`；轻量源码、日志与身份索引在Git目录。只有轻量证据的机器可以新渲染作品，不能声称重放了缺失的历史包。
