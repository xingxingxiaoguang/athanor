另从原 MVP 提交 `1af6fe8` 在隔离目录实际生成 v1 run，再交给新工具验证和重渲染：冻结源码检查通过、sourceDigest 一致、颜色 PNG 字节一致、后端仍为 lab-fixed-120-v1。对刀光、爆炸、火焰、瀑布、黑洞、冻结、燃烧转场、成就提示八个代表作品做了新适配器取样，覆盖 create/draw、单次/循环、身体和整屏模式，均可渲染；这不是全库视觉质量测评。

固定 tick 的回归另发现并修正了模拟绘制时钟在 0.2 秒附近的累计误差。新实验后端为 `lab-fixed-120-v2`，绘制时间从 tick 数推导；原库 createFx 保持原状，旧 run 使用它保存的后端。

## B 阶段首个纵向闭环

已增加独立的 `src/authoring/index.js` / `athanor/authoring`，避免将新依赖拉进244个原效果的旧 core 入口。真实实现与公开查询包括：

| 能力 | 当前子集 | 关键契约 |
| --- | --- | --- |
| path/strip | 折线、自适应三次曲线、弧长、切法线、重采样、连续可变宽条带 | 头尾区间与形状/材质开放；不是离散粒子主体；退化与预算显式报错 |
| random/curve | 稳定具名通道、分段线性/保持/平滑曲线 | 改色不重排运动随机；域、单位、边界明确，不冒充任意贝塞尔曲线 |
| domain/schedule/motion | 圆/矩形/路径/mask面积与边界、mask密度、出生排期、年龄、解析阻力弹道和沿线运动 | 位置采样不隐含初速度；方向由作者决定；出生身份与输出fps独立 |
| mask/field/image/light | 程序mask、布尔/轮廓、标量/噪声/排序/首次到达、保留/边缘/真实区间变化、稳定衍生出生及同源光 | 不混淆有符号噪声、排名、像素距离、时间；区间差分不伪造瞬时事件；新颜色边界检查hex/Color32 |

可调用组合参考 `lab/ember-weave` 已渲染、实际观察并验证；此首批交付时为五份机制配方与14族 SDK 契约（本版已增至六份/17族），作者可替换轮廓、路径、排序与材质。SDK 集成测试覆盖颜色局改保覆盖、随机局改保样本、不同帧率/跳转下首次出生一致、动态场同阈值真实增删、空间/修订冲突、冻结SDK闭包重放和包入口。

A 阶段独立复杂任务“断环引雷”及两次缺陷修复补测已[归档](../../experiments/vfx-lab/evaluations/2026-11-05-phase-a/README.md)。它揭示并促成：普通helper/坏模块不再阻断全库搜索，诊断给出实际候选与排除建议；效果源码语法错误不再误报参数JSON错误。测试B闭包又发现文本正则误把字符串中的 from 当作导入，依赖收集已改用Node自身模块语法解析。

每完成一个功能闭环必须有新独立创作者，不读实现、使用固定隔离构建完成复杂原创与局改；约定已写入根 AGENTS.md 和[测评流程](creator-evaluation.md)。B轮[“纸灯解缚”](../../experiments/vfx-lab/evaluations/2026-11-05-phase-b/README.md)已完成四版原创、两类局改、公开身份/时序、颜色/光/跨fps核验与冻结交付；未发现运行或SDK契约错误。它暴露的手写颜色/光窗口裁图负担已由 compare.channel 消除，并经其独立补测；第三位新作者另测观察闭环并定位、复核了弱光显示故障。技术运行与创作测评不被混为一项“通过”。

## 保存通道观察闭环

由独立创作者真实负担驱动，compare新增 preview/color/light/combined，沿用同原点、原尺寸、自选事件/绝对时间窗口。它读取保存图像，即使当前源码或依赖已损坏也不执行；报告 channel、saved-images、实际采样与观察底，不冒充内部层。页面比较沿用当前观察通道。

PNG读入无新外部依赖，检查CRC、格式、尺寸与预算，覆盖五种RGBA8 PNG滤波；坏图、截断原始缓冲和非法帧矩形不以空画面冒充成功。回归包含旧目标源码删除后的四通道窗口、透明RGB与坏产物拒绝。完整内部场/轨迹探测仍未实现。

B作者公开补测已证实无需原来的约二十行PIL裁图；[第三位新作者“暗潮墨蝶”](../../experiments/vfx-lab/evaluations/2026-11-05-phase-c/README.md)已完成三版原创、两类局改和四通道观察，确认无需自写裁图；它发现极弱光在灰底被显示成更暗剪影。修复为黑色加法中性底、曝光1后，独立补测确认1794个原发光像素未变、剪影消失、旧run在当前源码不可导入时仍可观察，其他通道与取样一致。

## 创作测评带来的补充改进

不仅采纳作者报告，也复核其作品中的重复工程：B/C都手写了通用多边形点内扫描。现有 `mask.polygon` 承担偶奇填充，顶点、栅格和开口仍由作者控制；B作者删除自写扫描后，区域/出生/四张图集73帧逐像素及PNG哈希一致，进一步扩大开口也通过。检索polygon与polygon→derive示例缺口在独立补测后补齐。

页面还验证了通道选择沿用到比较、光画布使用黑底，示例独有控件不会注入其他作品，0.012等光参数不会被滑块步进改写，显示与保存值保持对应。它仍是观察页面，非节点编辑器或完整参数编辑器；旧run播放不依赖当前作品存在。

## 后续实施顺序

1. **下一闭环：带速度的源轨迹与接触机制。** 粒子闭环及第四位独立作者测评已完成；其报告指出共享针尖运动仍需手算源速度。先提炼现有flyV、出生源、路径切向与曲线速度，再按库内sparkAt/sim的接触实现扩展一次性碰撞事件、二次发射或历史尾迹，分别过新独立创作者门。命名路径/mask观察尚未随粒子接口一并交付。
2. **B后续：身体表面与更完整运动。** 已有scalar/rank/arrival、程序mask/polygon、dissolve/change与同源衍生；下一步连接身体像素、轮廓/表面、裂纹传播与动作时钟，按真实作品需要扩展接触、历史轨迹或约束。保持坐标/单位/身份和结束策略明确，不能把静态排序场冒充完整物理或身体适配。
3. **B 阶段验收。** 用“非对称熔渣内收与冲拳”和“角色结霜后沿裂纹消失”两条完整场景，验证原创、局部修改和冻结复验。先完成代表性部件，不重写全库。有限色、弱光和非粒子主体同样可用。
4. **C：局部复用与观察实验。** probe仅首批保存图像/已声明粒子子集已开放；继续完善其他观察协议与reuse/explore，登记成熟辅助部件及依赖、来源、替换点和隔离预览。没有真实内部观测点的旧模块仍只承诺整体观察。
5. **独立创作者复核与 D。** 使用公开定义、普通编辑与图像证据进行创作测评，建立对照后再报告效率/表达收益；按真实需求扩展图像流动、身体适配、资产包、缓存和目标引擎交付。

B 阶段完整验收仍需身体表面/裂纹传播及真实动作适配等场景。任意内部层/mask/场探测、碰撞/接触二次发射、历史拖尾、完整向量场/图像流动、正式复用装配、引擎导入等 C–D 目标尚未实现。不从有限创作测评推断完整动作、外部MCP客户端认证或Unity/Godot导入已验证。

## 粒子、贴图与库内材质闭环（2026-11-06）

两大基石作为工程准则已写入根AGENTS与产品方案。[实现地图](implementation-map.md)记录每项库内代码路径、直接复用或通用化的决定；[当前参考构建](../../experiments/vfx-lab/research/tsnm-spine-particle/2026-11-06-particle-loop.md)记录生产脚本hash及发射/力场/选帧机制，不声称取得完整开发源码。
