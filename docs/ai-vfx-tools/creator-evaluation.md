# 独立创作者验收

有实质创作后果的功能波启动新独立上下文作者，在隔离快照记录构建摘要。规范见根目录 AGENTS；小型确定改善可以分组，确认问题的修复用单独补测。

作者只读公开指南、API、例子和通过公开 inspect 获取的参考效果源码，不读工具/runtime/SDK 实现、测试、sources.json、研发解释或他人方案。须实际观察原尺寸图，至少两次有意义局改并比较，明确选版、验证并导出同一冻结 run；相关变更实际走历史/重放/资产复用。

坦诚报告分别评价创意自由、具体帮助、可避免的手写工程及机制复用带来的实际能力；区分艺术选择与重复工程，不凭测试或代码量推断省时、美术优越或能力跃迁。

Git 只保留 `experiments/vfx-lab/evaluations/` 下简短原报告、构建身份摘要与复现入口。完整调用、原错误、各稿源码、原图、构建逐文件清单与导出归档在 ignored `records/vfx-lab/creator-evaluations/`，按需清理。原报告不重写；修复另加补测。2026-11-09 用户要求清除既有历史迭代输出，旧证据从当前树移除并在仓库外 Git bundle 中可恢复。
