# 每个创作闭环的独立测评

每个已可用功能闭环都按“公开契约与实现→必要技术验证→新独立复杂创作→问题修复与公开补测→证据归档”完成。SDK算法、可复用机制、观察和交付工作流同样适用。开发者示例、测试全绿或文档完整不能代替创作者实作。

## 独立性与任务

每轮新建不继承研发对话的子agent（`fork_turns:"none"`），在固定隔离副本工作，记录实际文件清单与build摘要，包含被测未提交实现。它可以调用tools/search/inspect、读公开API与参考效果源码，并用普通JavaScript编辑自己的作品；不能读工具/SDK/runtime实现、实现测试、冻结sources.json、研发交接或其他作者方案。operator inspect不得请求实现source。

新功能使用新作者；同一缺陷的修复补测可以沿用原作者。任务包含当下能力相关的复杂结构，容纳非粒子主体、材质、运动与因果组合，不能仅换预设颜色。机制提炼需要跨题材实作，避免把复做同一招式的熟悉度当工具帮助。

作者先写用途、尺度、意图与核心问题；实际观察初稿，再做至少两类有意义的局部修改。保留所需历史/重放证据，明确选定一个run，对该run验证并导出；媒体也必须对应同一选择。日常创作不强制走全部工具，测评只检验任务相关承诺。

## 三个判断维度

| 维度 | 必须说明的证据 | 不能替代的判断 |
| --- | --- | --- |
| 创意表达与帮助 | 哪种原创轮廓/运动/材质可表达或受阻，哪个机制实际提供帮助；保存原尺寸及必要弱光/有限色对照 | 运行成功、API数量、代码更短不等于艺术达成或表达更自由 |
| 使用负担 | 原始失败与恢复、实际往返；应由工具承担的解包/拼图/采样/时钟/观察适配是否仍手写 | 正常编辑、独特造型、构图和艺术取舍不能一律算产品负担 |
| 能力提升 | 流程/复用使哪个难点变得可组合；局改能否换结构而保留其他关系；哪些重复接线被替代 | 无匹配基线不宣称净省时、普遍艺术提升或“原本绝对做不出” |

不强制使用全部SDK。区分艺术扩展、可复用工程、作者误用、契约缺口和确认bug；作者自己的辅助脚本错误不自动归咎产品。开发者不得透露内部实现帮助黑盒作者通过。

可先用等价迁移核对某段公共工程被替代，再用新作者跨题材局改检验开放性。等价像素只能支持相应迁移结论；若报告时间/艺术收益，需相当目标、条件与熟悉度的对照。

## 生产方向的验收任务

这些是待实施工作包的测评要求，具体顺序见[研发交接](HANDOFF.md#9-后续研发路线具体工作包与验收)。

| 工作包 | 独立作者应实际做到什么 |
| --- | --- |
| 3.1 冻结动画交付 | 复杂原创含短峰值或长期残留/循环；改稿后选定冻结run，直接交付完整动画与atlas，不写解包/编码脚本；核对身份、帧数、时长和色光 |
| 3.2 时序观察与记录 | 在事件窗口比较两版，实际看原尺寸分段/播放证据；不用改作品、裁图/重排或造调用记录基础设施；活跃对象可找到 |
| 4 视口与边界 | 有意出画和无意越界分别检验；不包装底层写像素方法；颜色/光、翻转/旋转和冻结结果符合声明 |
| 5 动作与程序主体 | 动作、挂点、发射同步；非粒子主体共用变换/状态/观察；改材质或造型不重复同步；身体与裂纹联动完成对应B场景 |
| 6 技法复用与实验 | 在不同题材替换头尾/形状/材质/时序，来源/依赖明确；比较实质结构候选，不只换seed，也不自动判美 |
| 7 到达与聚合 | 到达引发累计量和主体变化，跳转/跨fps不重复；作者能改变目标、轨道和增长模型，不被球体预设限制 |

## 实际观察与声明范围

至少保存原生尺度关键帧与任务相关的顺序密集帧，记录请求/实际时刻及是否被宿主缩放。宽横表被压缩后应取得可实际辨认的原尺寸证据，不能用“已输出图片”替代“已查看”。

实际连续播放、局部循环/跳转、顺序密集帧、媒体元数据检查和全文件解码分别记录。调用端不能播放时如实说明，使用时间明确的帧证据；技术解码成功不能证明节奏、美感或观看已完成。不设GUI-only门槛或自动审美分数。

观察到的自定义状态只证明作者声明值被保存/查询；近似或占位velocity不自动成为位置导数一致性的证据。没有声明的旧主体不反推身份，点位连线不冒充真实历史。

## 交付与追踪

每轮保存brief、公开资料读取清单、调用输入/原始输出与错误、作品版本、实际看过的图、选版依据、同run验证/导出引用和坦诚报告。公共记录逐步由工具承担，作者补艺术解释和取舍；日志长度和调用次数不作为成绩。

原报告、原构建与失败保持不变。修复单独登记、用新摘要固定快照，由原作者仅通过公开入口补测。未完成独立门的功能标明“创作测评待完成”。完整act、外部资产、引擎导入、性能与独立MCP客户端认证不能从有限任务推断。

轻量功能证据放`experiments/vfx-lab/evaluations/`，大raw放ignored `records/vfx-lab/creator-evaluations/`。研发文档保持现行方向，不追加修订流水；原始证据及其边界不随路线整理改写。
