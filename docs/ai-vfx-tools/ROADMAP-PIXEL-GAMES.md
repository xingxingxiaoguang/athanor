# 后续迭代方向

更新：2026-11-08。从工具1.3继续；已完成节点见[历史索引](history/README.md)，当前事实见[状态](implementation-status.md)。本文只维护下一问题、候选范围与结束条件。

## 主线与取舍

AI 用普通 JavaScript 自由创作，借用成熟实现并连续局改；工具承担重复工程，提供准确诊断、原尺寸观察与可追溯交付。继续同时核对原库代码与参考平台底层机制，不按 API 数量或固定预设推进。

最近火球/烟雾生产完成了真实的局部复用与风格改稿，但不是新工具功能门。作品审美反馈和正式收录按用户准确范围处理，不阻塞工具研发。

## 下一轮优先：可编辑源码交付

**已有证据。** 多件母版交付重复编写了 `package-master.mjs`：复制 core/helper、重定位 import、生成独立单帧渲染入口、核对保存帧，并解压到仓库外验证。当前 export 的独立消费包和 history bundle 已承担资产消费/证据组织；作者仍额外维护可编辑项目。具体实例见[生产记录](../../experiments/vfx-lab/productions/history/2026-11-08-fireball-smoke.md)。这是维护者生产观察，尚非黑盒可用性或净节时结论。

**先调查什么。** 从可执行 export/replay/assets/source-parser 契约和冻结闭包出发，确认源码、资源、后端与依赖身份哪些已保存、哪些可独立运行。查相关既有算法；普通艺术源码不重新设计成 DSL。不能用当前工作树文件冒充选定 run 的冻结源码。

**候选闭环。** 若确有缺口，把明确选定 run 的可编辑项目交付做成可发现的公共流程，处理可支持的相对 JS/PNG 依赖、稳定入口、来源与许可、阻断诊断以及修改后的新版本身份；复用现有资产与证据模块。不能支持的依赖明确报告，不悄悄生成需要原仓库的包。

**结束条件。** 必要技术检查后，由新独立上下文作者在固定隔离构建，仅从公开指南/定义完成复杂原创和两类局改；选定同一冻结 run，移出仓库、缺原稿后实际打开可编辑交付，继续修改、观察和重新验证/导出。保留源码/帧身份、原错误、原尺寸图、坦诚报告与分离补测。没有适当对照不宣称净节时或美术优势。

## 其他候选按需求触发

| 观察到的问题 | 先用已有能力 | 何时再扩展 |
| --- | --- | --- |
| 未登记 helper 难发现或难拆用 | search/inspect reuse、原helper和material适配 | 新题材实际受阻，再补索引、契约或局部适配 |
| 共同像素网格、几何供烟、跨时钟需要手写 | 当前母版作为有来源的代码参考 | 不同原创任务反复出现同类工程，再评估公共渲染/共享状态接口 |
| 自定义 heat/size 难量化 | 共享函数、公开 data 与现有观察协议 | 原图局改不足以定位问题时，再扩观察范围 |
| 目标引擎接入 | 现有 playback、图层/pivot/事件/启停 | 有明确游戏项目后按其材质与资源系统验证 |

通用流体/碰撞全覆盖、人类节点编辑器、固定效果 DSL、自动审美评分和无需求的性能整理不预先排成主线。

## 每轮如何交回

真实摩擦 → 两大基石与已有实现 → 一组有明确范围的改动 → 必要技术检查与[独立创作者门](creator-evaluation.md) → 保留原件和分离补测 → 更新状态与下一问题。小而确定的修复合并；重要且无法判断的优化方向用独立 A/B 探路。
